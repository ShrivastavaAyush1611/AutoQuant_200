Project structure:
  index.html       Main page markup
  css/styles.css   Extracted styles
  js/app.js        Application logic

Dependency:
  jsQR is loaded from jsDelivr in index.html (requires internet access).

Run:
  Open index.html through HTTPS or localhost. Camera access generally does not
  work when opening the page directly with a file:// URL.
